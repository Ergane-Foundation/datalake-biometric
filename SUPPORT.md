# Getting help

- **Questions and ideas:** open a GitHub Discussion (Q&A or Ideas). Please search
  first; your question may already be answered.
- **Bugs:** open an issue with the bug report form. Include your platform, device,
  versions and the steps to reproduce.
- **Documentation problems:** open an issue with the documentation form.
- **Security problems:** do not post them publicly; follow [SECURITY.md](SECURITY.md).

Before asking, check:

- [README.md](README.md) and the [docs/](docs/) folder;
- that `yarn setup:models --check` passes (most "no face" or startup errors are
  missing models);
- the error `code` of the rejected promise, explained in
  [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md#error-codes).

This project is maintained by volunteers, so answers can take a few days. There
is no paid support.
